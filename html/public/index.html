Training Hub

Welcome to training hub. The purpose of this site is to provide you with a platform on which to manage a small project to design a website using github to manage the project. This server should give you all the tools to get a temporary github account to join your github organisation. To be assigned into groups and to clone a reposiroty from a template and start to engineer your own mini website project.

You will be given a tempory email address for this project with which you need to register an account on GitHub.

You will then be invited to join a project on GitHub where you will find a repository and a basic project board.

You can find your email server here. Your password is the group username + '-' + your account name. And you can only receive email to this address.

You can find your Jupyter server here. Use Jupyter to edit files and track your github repo.

Students

Start by registering a GitHub account at https://github.com/signup. You will need to use your temporary email address which should be of the form . The sign up process requires a Launch Code which you will receive by email. You will need to follow instructions in that email. You will also receive an invitation to join a team called pupils (this should happen automatically do not worry about this).

Once that is done your tutor will need to assign you to your team

You will then need to log into GitHub and navigate to your organisation

Please be aware that github is a real service. There are lots of ways to use it. Please use the service only for this project. Github will delete accounts if they are used inapropriately and it is easy to accidentally delete your work or remove yourselves from teams/organisations/reposiroties/and projects. Take care, you are in the professional world for this project.

Tutors and administrators

You will find a page showing the progress of your class' enrolement progress here. Once the class has registered for a github account they can be assigned to teams via that page.
