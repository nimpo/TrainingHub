Training Hub

Welcome to training hub. The purpose of this site is to provide you with a platform on which to manage a small project to design a website, using github to manage the project. This server should give you all the tools to get a GitHub account and to join our GitHub Organisation. Your account will be assigned into groups and you will have access to a templated repository. From that point you will be able to engineer your own mini-website project which will be served under pages..

You will be given a tempory, receive only email address for this project with which you need to register an account on GitHub. It can only receive authentic GitHub mail.

You will then be invited to join an Organisation on GitHub where you will find a repository and a basic project board.

You can find your email server here. Your password is the group code (ask your tutor) + '-' + your account name.

You can find your Jupyter server here. Use Jupyter to edit files and track your github repo.

Students

Start by registering a GitHub account at https://github.com/signup. You will then need to login to your temporary email address which should be of the form . The sign up process requires a Launch Code which you will receive by email. You will need to follow instructions in that email. You will also receive an invitation to join a group-wide team (this should happen automatically do not worry about this).

Once that is done your tutor will need to assign you to your specific team.

You will then need to log into GitHub and navigate to your Organisation.

Please be aware that GitHub is a real service. There are lots of ways to use it. Please use the service only for this project. Github will delete accounts if they are used inapropriately and it is easy to accidentally delete your work or remove yourselves from teams/organisations/reposiroties/and projects. Take care, you are in the professional world for this project.
